`@cloudflare/forge/ts` prints TypeScript files and works out their imports. The
[guide](/plugins/ts-printer/) shows how to use it; this page lists the API.

## module

Makes the modules a file can import from:

```ts
function module(path: string): Module;
module.ROOT: Module;                            // the output directory
module.group(group: { path: readonly Name[] }): Module;  // e.g. "petStore/listAll"

interface Module {
  /** The path, for a generated file, or the specifier, for a package. */
  readonly path: string;
  /** Whether the path ends in `.ts`. */
  readonly generated: boolean;
  ident(name: string): Ident;
  /** The module `name` inside this directory. */
  sub(name: string): Module;
  equals(other: Module): boolean;
  toString(): string;
}
```

A generated module is imported by a relative specifier ending in `.js`; a package by its path
unchanged.

## ident

Makes identifiers, which a file imports when it prints one from another module:

```ts
function ident(
  name: string,
  module: Module,
  options?: { typeOnly?: boolean; alias?: string },
): Ident;

/** A model's name in Pascal case, in the `models.ts` of its group or of the root. */
ident.model(model: { name: Name; group: Group | undefined }): Ident;

interface Ident {
  /** Such as `Pet`, or a dotted name such as `Temporal.Instant`. */
  readonly name: string;
  readonly module: Module;
  /** Imported with `import type` (or `type` in a mixed import). */
  readonly typeOnly: boolean;
  /** Imported as `name as alias`. */
  readonly alias: string | undefined;
  /** The same, as only a type. */
  ty(): Ident;
  /** The same, imported under `alias`. */
  as(alias: string): Ident;
  toString(): string;
}
```

A dotted name imports its first part: `Temporal.Instant` imports `Temporal`.

## file

Makes a file to print lines to:

```ts
function file(at: Module | string): File;

interface File {
  /** Prints a line: indentation, the parts, a line break. */
  (strings: TemplateStringsArray, ...parts: Part[]): void;
  /** Prints a line of parts; with none, a blank line. */
  (...parts: Part[]): void;

  readonly module: Module;
  readonly path: string;
  /** The rendered file, or an empty string if nothing was printed. */
  readonly content: string;

  /** An identifier declared in this file, never imported. */
  ident(name: string): Ident;
  /** Runs `f` with lines indented two more spaces. */
  indent(f: (file: File) => void): void;
  /** Prints a JSDoc comment, wrapped at 80 columns. Nothing for empty text. */
  doc(text: string): void;
  render(): string;
}
```

A `File` has `path` and `content`, so it is a plugin [file](/reference/plugin-api/#defineplugin) as
it is.

## Parts

What a line can print, and the helpers that build parts of one:

```ts
type Part = string | number | boolean | bigint | Ident | Model | readonly Part[];

function frag(strings: TemplateStringsArray, ...parts: Part[]): Part[];
function join(sep: string, parts: Iterable<Part>): Part[];
const PREAMBLE: string;
```

- Strings print as they are; numbers, booleans and bigints as `String` writes them.
- An `Ident` prints as the name the file uses for it, and is imported if it is from another module.
- A `Model` prints as `ident.model(model)`.
- An array prints each part in turn, with nothing between.
- Anything else throws.

`join` leaves out parts that print nothing. `PREAMBLE` is the two lines every rendered file starts
with:

```ts
// Code generated by forge. DO NOT EDIT.
/* eslint-disable */
```

## Rendering rules

- Imports: packages first, then generated files, a blank line between the two, each sorted by
  specifier; one declaration per module.
- A module whose imported names are all types is imported with `import type`. A name used as both a
  type and a value is imported as a value.
- A declaration that fits in 80 columns, or has one name, is on one line; otherwise one name per
  line.
- An imported name that clashes with one declared in the file, or an earlier import, gets `$`
  appended until it is unique.
- A file with nothing printed renders as an empty string.
