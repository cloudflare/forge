`--target ts` writes a TypeScript SDK with no dependencies: a client per group, a model per schema,
codecs where the wire and the language differ, and a small runtime it ships alongside.

```sh
forge openapi.json --target ts --out sdk
```

## What it writes

Each group gets a directory, named in camel case, with three files. The root has the same three,
and the runtime in `_/`:

```text
sdk/
├── _/                 the runtime: transport, codecs, errors, hooks
├── client.ts          createClient, and a property per top-level group
├── models.ts          models used by more than one top-level group (if any)
├── index.ts           what to import
└── pets/
    ├── client.ts      the group's methods, request and response types
    ├── models.ts      the group's models and their codecs
    └── index.ts
```

Every file starts with `// Code generated by forge. DO NOT EDIT.` and `/* eslint-disable */`.
Imports between files use `.js` specifiers, which TypeScript resolves to the `.ts` files, so the
output works with `"moduleResolution": "nodenext"` or `"bundler"`.

## Clients

`createClient` takes the options every client needs, and returns an object with a property per
top-level group, each with a property per subgroup and a function per method:

```ts
import { createClient } from './sdk/index.js';

const client = createClient({
  baseUrl: 'https://api.example.com/v1',
  token: process.env.API_TOKEN!,
});

const pets = await client.pets.list({ limit: 10 });
```

| Option     | Meaning                                                                |
| ---------- | ---------------------------------------------------------------------- |
| `token`    | Required. Sent as `Authorization: Bearer <token>`.                     |
| `baseUrl`  | Required at the root. The URL the paths are relative to.               |
| `fetch`    | The `fetch` to send requests with; the global one by default.          |
| `headers`  | Headers sent with every request.                                       |
| `query`    | Query parameters sent with every request, as `URLSearchParams`.        |

Group clients are created on first access, so a large API costs nothing for the groups you do not
use. Each group directory also exports its own `createClient`, for code that only needs one group.

## Methods

Each method takes its [request](/concepts/requests-and-responses/) as one object, then per-call
options, and returns a promise of the response:

```ts
create(request: CreateRequest, options?: RequestOptions): Promise<CreateResponse>;
list(request?: ListRequest, options?: RequestOptions): Promise<ListResponse>;
```

The request is optional when none of its fields is required. Its type is exported:

```ts
export type CreateRequest = NewPet;          // a body and no parameters

export interface DeleteRequest {             // a path parameter
  petId: string;
}

export interface ListRequest {               // a query parameter
  limit?: number;
}
```

Fields are named in camel case and mapped back to their wire names when sent. The response type is
the union of every `2XX` body, or `void` when there is none.

`RequestOptions` are:

| Option       | Meaning                                                    |
| ------------ | ---------------------------------------------------------- |
| `signal`     | An `AbortSignal` to cancel the request.                    |
| `headers`    | Headers for this call, replacing the client's.             |
| `query`      | Query parameters appended after the client's.              |
| `onResponse` | Called with the `Response` before its body is read.        |

## Models

Each model is an `interface` (or a `type` alias, for models that are not objects) in the
`models.ts` of the group it is [placed in](/concepts/models/), with its description as a doc comment
and `@deprecated` when the schema is:

```ts
/**
 * A pet in the store.
 */
export interface Pet {
  bornAt?: Temporal.Instant;
  id: string;
  name: string;
}
```

Fields are sorted by wire name. Types map as:

| Schema                          | TypeScript                                  |
| ------------------------------- | ------------------------------------------- |
| `string`                        | `string`                                    |
| `integer`, `number`             | `number`                                    |
| `format: int64`                 | `bigint`                                    |
| `format: date-time`             | `Temporal.Instant`                          |
| `format: date`                  | `Temporal.PlainDate`                        |
| `format: byte`                  | `Uint8Array`                                |
| `enum`                          | A union of literals                         |
| `anyOf`, `oneOf`, nullable      | A union                                     |
| `allOf`                         | An intersection                             |
| `additionalProperties` only     | `{ [key: string]: T }`                      |

## Codecs

When a model's JSON differs from its TypeScript (a renamed field, an instant, a `bigint`, bytes),
the SDK generates a codec for it, such as `PetCodec`, that converts in both directions. A model whose
JSON is already its TypeScript has no codec, and costs nothing at run time.

```ts
export const PetCodec = object([
  ["born_at", "bornAt", instant],
]);
```

Codecs are internal; you work with the decoded values.

## Errors

A non-`2XX` response throws an `ApiError`:

```ts
import { ApiError } from './sdk/index.js';

try {
  await client.pets.delete({ petId: 'p2' });
} catch (err) {
  if (err instanceof ApiError) {
    console.error(err.status, err.message, err.details);
  }
}
```

| Member     | Meaning                                                                    |
| ---------- | -------------------------------------------------------------------------- |
| `status`   | The response status.                                                       |
| `message`  | From a JSON body: its `message`, `error`, `detail` or `title`, a nested `error.message`, or every `errors[].message` joined by `; `. Otherwise the status and status text, such as `404 Not Found`. |
| `details`  | The body decoded as the error the API declares for the status, or the text, or undefined when empty. |
| `response` | The `Response`, whose body has been read.                                  |

## Customizing: the envelope hook

Some APIs wrap every payload, as in `{ "success": true, "result": { ... } }`. The runtime calls
`unwrapEnvelope(response, body)` in `_/hooks/envelope.ts` on every `2XX` JSON body before decoding it.
The generated one returns the body as it is; replace the file with one that returns the part your
document's schemas describe.

Forge writes `_/hooks/envelope.ts` again on every run, so keep your version somewhere else and copy
it over after each run.

## Requirements

The SDK uses `fetch`, `URLSearchParams`, `AbortSignal` and `Temporal`, all as globals. Node.js 26
has all of them. In runtimes without `Temporal`, load a polyfill that defines the global before using
the SDK.
