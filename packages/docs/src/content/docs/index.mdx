---
title: Forge
description: One OpenAPI document in; an SDK, MCP tools, a server or your own output out.
---

Forge reads an OpenAPI document into one typed model, then hands it to plugins that write SDKs, MCP
tools, servers and docs. The targets that ship with Forge are plugins too, so yours gets the same
model they do.
