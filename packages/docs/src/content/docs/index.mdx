    <h2 class="text-3xl font-semibold tracking-[-0.025em]">How it works</h2>
    <p class="mt-3 max-w-2xl text-muted-foreground">Forge does the shared part once. A plugin does the part that belongs to one language.</p>

    <div class="mt-10">
      <CardGrid class="lg:grid-cols-3">
        <Card title="1. Read" icon="ph:file-code">Forge parses the document and follows every `$ref` to a parameter, body, response or schema.</Card>
        <Card title="2. Model" icon="ph:tree-structure">It decides what is a group, a method and a model, and names each one, once for every target.</Card>
        <Card title="3. Generate" icon="ph:lightning">A plugin takes the model and returns files. Forge writes them, and a plugin cannot write outside `--out`.</Card>

```ts title="plugin.ts"
import { definePlugin } from '@cloudflare/forge/plugin';

export const { generate } = definePlugin({
  generate(forge) {
    return forge.groups
      .filter((group) => group.methods.length > 0)
      .map((group) => ({
        path: [...group.path.map((name) => name.kebab()), 'methods.txt'].join('/'),
        content: group.methods.map((m) => m.name.camel()).join('\n'),
      }));
  },
});
```
