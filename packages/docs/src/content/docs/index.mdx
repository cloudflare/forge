---
title: Forge
description: Forge generates SDKs, MCP tools, servers and anything a plugin writes from a shared API model. Today, its input is one bundled OpenAPI JSON document.
content_type: overview
---

Forge builds one typed model of an API, then hands it to plugins that write SDKs, MCP tools, servers
and docs. The targets that ship with Forge are plugins too, so yours gets the same model they do.
[Install Forge](/start/install/), then [get started](/start/get-started/).

<Aside type="note" title="Input support today">
Forge currently accepts one bundled OpenAPI 3.0, 3.1 or 3.2 document as JSON. AsyncAPI, other API
description formats and multiple source files are future directions, not supported inputs. OpenAPI
written as YAML or split across files must be converted and bundled first.
</Aside>
