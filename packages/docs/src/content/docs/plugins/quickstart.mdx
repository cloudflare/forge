Forge's built-in targets are plugins, and writing your own takes one file. This page writes one in
TypeScript, runs it on the pet store document from the [quickstart](/start/quickstart/#1-write-a-document),
and shows what it writes. Save that document as `openapi.json` first.

## Write the plugin

This plugin writes a README, and a table of the methods of every group that has any:

```ts title="plugin.ts"
import { definePlugin } from '@cloudflare/forge/plugin';

export const { generate } = definePlugin({
  generate(forge) {
    const readme = { path: 'README.md', content: `# ${forge.description}\n\nVersion ${forge.version}.\n` };
    const pages = forge.groups.filter((group) => group.methods.length > 0).map((group) => {
      const rows = group.methods.map((m) => `| \`${m.name.camel()}\` | \`${m.httpMethod} ${m.path}\` |`);
      const table = ['| Method | Route |', '| --- | --- |', ...rows].join('\n');
      const path = group.path.length > 0 ? group.path.map((n) => n.kebab()).join('/') : 'index';
      return { path: `${path}.md`, content: `${table}\n` };
    });
    return [readme, ...pages];
  },
});
```

`forge.groups` has every group, including the root, whose path is empty, so its table goes in
`index.md`; the filter leaves out groups with no methods.

## Build and run it

Install Forge's npm package, which has `forge-plugin` and the `@cloudflare/forge/plugin` library,
and jco, which `forge-plugin build` uses:

<PackageManagers pkg="https://pkg.pr.new/cloudflare/forge/@cloudflare/forge@main @bytecodealliance/jco" dev />

Build the plugin into a WebAssembly component, and run it:

<PackageManagers type="exec" pkg="forge-plugin" args="build plugin.ts --out plugin.wasm" />

```sh
forge openapi.json --target wasm://plugin.wasm --out docs
```

`docs/pets.md` now has a table of the three methods:

```md title="docs/pets.md"
| Method | Route |
| --- | --- |
| `create` | `POST /pets` |
| `delete` | `DELETE /pets/{pet_id}` |
| `list` | `GET /pets` |
```

The plugin ran sandboxed: it read the document's model, and returned files for Forge to write. It
could not read files, reach the network or see the environment; see
[the sandbox](/concepts/sandbox/) for exactly what it has.
