`parse` from `@cloudflare/forge` reads an OpenAPI document into [the model](/concepts/the-model/)
in your own process. It returns the same `Forge` a [TypeScript plugin](/plugins/typescript/)
receives, with the same groups, methods, models and types. Use it when a tool needs the model but
does not generate files, such as a docs site that lists an API's methods.

It runs Forge compiled to WebAssembly, so it needs neither the `forge` binary nor a plugin.

## Prerequisites

- Node.js 18 or later.
- A document to read, such as the pet store document from
  [Get started](/start/get-started/#1-write-a-document), saved as `openapi.json`.

## 1. Install the package

`parse` is the main export of Forge's package:

<PackageManagers pkg="https://pkg.pr.new/cloudflare/forge/@cloudflare/forge@main" dev />

## 2. Parse a document

`parse` takes the document as JSON text, and returns its `Forge`. This script prints every method:

```js title="routes.mjs"
import { readFile } from 'node:fs/promises';
import { parse } from '@cloudflare/forge';

const forge = parse(await readFile('openapi.json', 'utf8'));
for (const group of forge.groups) {
  for (const method of group.methods) {
    console.log(method.httpMethod, method.path, method.name.camel());
  }
}
```

Run it:

```sh
node routes.mjs
```

It prints the three methods of the pet store document:

```text
POST /pets create
DELETE /pets/{pet_id} delete
GET /pets list
```

Every type and property of the result is in the [Plugin API](/reference/plugin-api/#the-model).
`@cloudflare/forge` exports the same model types as `@cloudflare/forge/plugin`. Each call returns a
forge of its own, so several documents can be read side by side, such as one for each version of an
API.

## Normalize extensions before parsing

`parse` reads only Forge's native `x-forge-*` extensions. If a document uses extensions from a
compatibility mode, pass it through `normalize` first:

```js title="normalize-and-parse.mjs"
import { readFile } from 'node:fs/promises';
import { normalize, parse } from '@cloudflare/forge';

const raw = await readFile('openapi.json', 'utf8');
const forge = parse(normalize(raw));
```

`normalize` returns the rewritten JSON string, or the input unchanged when nothing needed rewriting.
By default it applies every compatibility mode listed under **Compatibility Modes** in the sidebar.
Pass `options` to limit the adapters or keep the original keys alongside the native ones:

```js
const normalized = normalize(raw, {
  adapters: ['cloudflare'],
  leaveOldExtensions: true,
});
```

## Errors

`parse` and `normalize` throw an `Error` when Forge cannot read the document, with the message the
`forge` command prints after `forge: ` and the file name. A document with no `openapi` key, such as
a Swagger 2.0 document, throws:

```text
the document has no openapi version: only OpenAPI 3.0, 3.1 and 3.2 are read
```

Refer to [Troubleshooting OpenAPI documents](/openapi/errors/) for each message.
